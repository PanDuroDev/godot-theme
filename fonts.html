Add to your project

A. npm (automatic) — install once, the bundler emits the font files, godot.css loads them. Nothing to declare:

npm install godot-theme
import 'godot-theme';                            // godot.css + fonts, via exports "."
import { tokens } from 'godot-theme/tokens.js';  // 38 tokens in JS
import addIcon from 'godot-theme/icons/Add.svg';  // any icon / font file, same way

B. plain CSS / static site — unzip godot-theme-fonts.zip next to your css and declare the faces:

@font-face{font-family:'Inter';font-weight:400;font-display:swap;
  src:url('fonts/Inter_Regular.woff2') format('woff2')}
@font-face{font-family:'Inter';font-weight:700;font-display:swap;
  src:url('fonts/Inter_Bold.woff2') format('woff2')}
@font-face{font-family:'Vazirmatn';font-weight:400;font-display:swap;
  src:url('fonts/Vazirmatn_Regular.woff2') format('woff2')}
@font-face{font-family:'Vazirmatn';font-weight:700;font-display:swap;
  src:url('fonts/Vazirmatn_Bold.woff2') format('woff2')}
@font-face{font-family:'JetBrains Mono';font-weight:400;font-display:swap;
  src:url('fonts/JetBrainsMono_Regular.woff2') format('woff2')}
body{font-family:"Inter","Vazirmatn","Segoe UI",Tahoma,sans-serif}
code{font-family:"JetBrains Mono",Consolas,monospace}

C. React component — classes are plain CSS, so className just works; helpers live on window.GodotDS:

import 'godot-theme/js'; // side-effect once (window.GodotDS)
import addIcon from 'godot-theme/icons/Add.svg';

export function NewButton({ onClick }) {
  return (
    <button className="btn" onClick={onClick}>
      <img src={addIcon} width={16} height={16} alt="" />
      <span>New</span>
    </button>
  );
}
const { toast, openDialog } = window.GodotDS;

GTGodot Theme

Godot Modern, as a library

The Godot 4.6+ dark editor theme — vanilla CSS + tiny JS helpers for Electron apps. Quoted from godot-launcher first, sourced from godotengine/godot master always.

npm install godot-theme
MIT · no dependencies · works over file:// with zero build

Install — pick one

npm install godot-theme           # 1) npm package
npm install ../godot-theme        #    alternative: install from local path
<!-- 2) direct link after install: -->
<link rel="stylesheet" href="node_modules/godot-theme/godot.css">
<script src="node_modules/godot-theme/godot.js"></script>
<!-- 3) copy the folder next to your app: -->
<link rel="stylesheet" href="../godot-theme/godot.css">
<script src="../godot-theme/godot.js"></script>

Use in 30 seconds

<button class="btn"><img src="godot-theme/icons/Add.svg"><span>New</span></button>
<script>
  GodotDS.toast('Engine downloaded', 'success');
  GodotDS.openDialog('dlgNew');
  GodotDS.bindSearch('search', 'searchClear');
</script>

Develop the library itself (maintainers)

npm install
npm run dev      # docs site + HMR — http://localhost:5173
npm run build    # static dist/ + packed library file for download
npm run serve    # serve dist/ locally — :4173
npm adduser      # once: create / login npm account
npm publish --access public  # publish (name godot-theme is free); bump version before each re-publish
npm test         # smoke + coverage + tokens + consumer-pack check
